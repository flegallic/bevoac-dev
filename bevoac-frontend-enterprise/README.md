# Bevoac frontend — DEMO ONLY

This package is an explicitly non-contractual demonstration UI for Bevoac V6.2.0.

It:

- displays synthetic data only;
- does not accept customer API keys;
- does not proxy API requests;
- does not launch scans;
- is not part of the production API service commitment;
- must not be presented as a live customer portal.

The production deliverable is the Bevoac API exposed through the approved APIM endpoint and documented client workflows.

A production customer portal requires a separate product workstream with server-side authentication, tenant sessions, authorization, audit logging, secure key management, end-to-end tests, and its own acceptance gates.
