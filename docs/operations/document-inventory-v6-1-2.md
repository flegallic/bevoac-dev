# Inventaire documentaire actif V6.1.2-R3

Le corpus actif est limité aux documents V6.1.2-R3 listés dans `docs/README.md`. Les documents V5/V6.1.1 sont archivés ou conservés dans `_source_reference`.

Le fichier `manifests/document_inventory.csv` du package d'alignement constitue la matrice chemin par chemin. Toute nouvelle documentation active doit :

- avoir une version explicite ;
- indiquer son statut de preuve ;
- pointer vers le runbook canonique ;
- éviter de dupliquer une procédure complète ;
- être couverte par le validateur documentaire.
