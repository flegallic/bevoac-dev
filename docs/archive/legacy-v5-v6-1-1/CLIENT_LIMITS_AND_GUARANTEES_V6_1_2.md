# Bevoac V6.1.2 - garanties et limites client

## Garanties presentables

- API B2B Azure-first.
- APIM obligatoire en production controlee.
- Tenant derive de la cle API.
- Cibles web/Azure autorisees avant scan.
- Resultats JSON complets disponibles explicitement.
- PDF oriente findings/remediation/evidence.
- Historique de scans.
- Billing/quota/backpressure.
- Worker asynchrone avec outbox.

## Limites a annoncer clairement

- AWS est en fondation technique, pas runtime-enabled.
- La certification enterprise necessite pentest externe et dossier de preuves.
- Le score PDF est un indicateur technique, pas une certification reglementaire.
- Les scans web necessitent une autorisation explicite du client.
