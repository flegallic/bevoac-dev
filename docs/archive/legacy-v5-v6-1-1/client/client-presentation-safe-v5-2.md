# Bevoac V5.2 - presentation client-safe

## Positionnement correct

Bevoac V5.2 est une API Azure-first d'audit de securite declenche ou recurrent, orientee JSON exploitable et rapport PDF finding/remediation/evidence.

## Ce qui peut etre presente

- API de lancement et suivi de scans.
- Scans web autorises par allowlist.
- Scans Azure sur subscriptions verifiees.
- Historique de scans.
- JSON complet.
- Rapport PDF lisible.
- Idempotence.
- Outbox transactionnelle.
- Billing state transparent.
- Alerting et retention en environnement pilote.
- APIM optionnel pour exposition gateway.

## Ce qu'il ne faut pas promettre

- Bevoac n'est pas une CNAPP complete.
- Bevoac ne remplace pas Defender for Cloud, Wiz ou Orca.
- AWS/GCP ne sont pas livres.
- Production enterprise non certifiee.
- Conformite ou pentest non garantis sans preuves.

## Formulation conseillee

Bevoac V5.2 fournit un socle API Azure-first permettant de cadrer un pilote B2B d'audit continu, avec resultats JSON, rapports PDF et controles d'exploitation, sous reserve des validations client et securite convenues.
