# Reporting JSON et PDF V6.1.2

Le JSON est la source exhaustive. Le PDF est un rendu borné pour client/CTO/RSSI.

## Contenu

- résumé exécutif ;
- contrôles, findings, remédiations et preuves ;
- KPI Scorecard ;
- métadonnées d'exécution ;
- taille/hash du résultat ;
- aucune clé ou secret.

## Bornes

Timeout de génération, taille JSON, nombre de findings et d'éléments de preuve. Le PDF n'est générable que si un résultat existe.
